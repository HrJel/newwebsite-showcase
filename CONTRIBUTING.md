# Contributing to this portfolio showcase

This repository is curated by Jelvan R. as a public portfolio presentation. You may submit corrections to **public documentation** through issues or pull requests if enabled, but **do not** post client information, internal implementation details, actual API endpoints, screenshots containing personal data, or private code.

All submissions are reviewed for confidentiality, accuracy, originality and potential third-party rights. Publication does not guarantee acceptance. Do not interpret acceptance as granting access to the original application.
