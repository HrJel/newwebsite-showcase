# Screenshot/media upload policy

This directory intentionally contains no application screenshots. Add **only** approved, anonymized demo media with synthetic data. Never upload screenshots of real mailboxes, clients, employee records, customer orders, OTP enrollment codes or secret-bearing consoles.

Recommended names: `desktop-preview.webp`, `mobile-ios-preview.webp`, `mobile-android-preview.webp`. Prefer 1440×900 for desktop and 390×844 for mobile captures. A screenshot must be described as a simulation if it is not an actual build.
